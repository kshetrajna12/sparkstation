Voice Studio

idle

WebSocket transport (/voice/talk → bot /ws-client), 16 kHz in / 24 kHz out. The mic needs a secure context (localhost or HTTPS). One session at a time — a busy bot closes with 4429.

Clone a voice from a reference clip

Record or upload 8–12 s of natural speech (max 20 s — longer references make cloned speech choppy) and type its exact transcript. The clip is stored only in the voice registry on the voice host, never in git.

Cluster & models

Start a model

Resolved through the selected profile exactly like sparkstation models start <alias> -p <profile>. Chat models on the same node are usually mutually exclusive — the supervisor checks the target host's free memory before launching (model + 10 GB headroom must fit) and refuses cleanly if it doesn't.
